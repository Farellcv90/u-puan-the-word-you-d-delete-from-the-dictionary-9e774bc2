One word, erased from the dictionary forever: **no**.

Erase it and nobody can refuse anything ever again — no declining, no
disagreeing, no "no thanks". Every toddler, every meeting, every sales
call: yes to everything, forever. The joke is the gap the word leaves
behind, and it lands the moment the word is gone.

## How it works

`main.py` writes the single word `no` to `/output/entry.txt` — no
trailing newline, nothing else attached. It first validates the gate:
the entry must be UTF-8 text of 1–77 characters, not only whitespace.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
